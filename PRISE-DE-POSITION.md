# Prises de position

Positions prises sur le produit et la technique, avec leur raison et le levier a actionner si le point pose probleme. A relire avant de remettre une decision en question.

| Date | Sujet | Position | Raison | Levier si ca coince |
|------|-------|----------|--------|---------------------|
| 2026-10-23 | Transcription | Ne pas transcrire la VOD entiere : transcrire ~60 s autour de chaque pic de chat. Transcription integrale seulement si le chat est calme et que la banque de clips de reference doit prendre le relais | Cout et temps de calcul sur un VPS partage | Elargir la fenetre autour des pics ; transcrire en entier uniquement les VODs sans pic ; deleguer a une API payante a la minute |
| 2026-10-23 | Chat des VODs | GraphQL non officiel de Twitch | L'API officielle ne fournit pas le chat des VODs | Si l'endpoint change : corriger `twitchChat.ts` (hash, format). Plan B : capturer le chat en direct pendant le live. **Levier actionne le 2026-10-23** : le curseur exige un jeton d'integrite, `twitchChat.ts` pagine desormais par offset (hash et client-id inchanges). Si l'offset est lui aussi verrouille : Plan B |
| 2026-10-23 | Recuperation des VODs | Automatique (EventSub + liste des videos), lien manuel seulement en option | Le streamer ne doit rien faire ; clipping a la fin du stream voire pendant | Si EventSub pose probleme : interroger Twitch a intervalle regulier ; sinon lien manuel |
| 2026-10-23 | Hebergement du rendu | VPS existant, un rendu a la fois, process separe du site | Seule option peu couteuse connue | Limiter la priorite CPU (`nice`), reduire la resolution/qualite de rendu, ou deporter le rendu sur un serveur dedie |
| 2026-10-23 | Declenchement des clips | Le chat et la banque de clips de reference sont deux sources independantes ; aucune n'est obligatoire seule | Chat calme => pas de clip issu du chat | Ajuster les seuils de `chatPeaks` (`minScore`, `minMessages`) ou les mots-cles du streamer |
| 2026-10-23 | Validation | Rien n'est publie ni paye sans accord humain ; clips envoyes par lots de 4 | Controle qualite et confiance du streamer | Augmenter la taille des lots une fois la qualite eprouvee |
| 2026-10-23 | Reseaux Meta / TikTok | Hors perimetre V2 pour les stats de clips | Pas d'application approuvee accessible | Utiliser les stats Twitch Clips et YouTube ; reevaluer plus tard |
| 2026-10-23 | Cles Twitch | Une seule application Clippeak pour tous les streamers, jeton d'application (client credentials), pas de connexion du streamer pour la V2 | VODs publiques, notifications EventSub de stream et chat GraphQL n'exigent pas l'accord du streamer ; il ne donne que son pseudo | Ajouter OAuth (redirection deja declaree) si besoin de VODs reservees aux abonnes ou de comptes streamers |
| 2026-10-23 | Notifications Twitch | Reponse immediate puis traitement en arriere-plan ; VOD retrouvee par `stream_id` avec 6 tentatives espacees de 20 s | Twitch exige une reponse rapide et la VOD apparait avec un leger retard | Allonger `retries`/`retryDelayMs` ; ajouter un polling de rattrapage |
| 2026-10-23 | Rattrapage des notifications | Polling toutes les 5 min dans le process Nuxt (plugin Nitro), limite aux VODs posterieures a la creation du Channel | Leger (2 appels Helix par passage, `/streams` groupe par 100) ; l'historique ancien n'est analyse que sur decision explicite | Changer `TWITCH_CATCHUP_INTERVAL_SEC` ; si plusieurs instances pm2 : deplacer dans le worker separe ; pour importer l'historique : ajouter une action admin dediee |
| 2026-10-23 | File de rendu | File = table `clip_jobs` (pas de Redis), worker pm2 separe, un rendu a la fois, ffmpeg en priorite basse ; demarrage manuel tant que le rendu reel n'existe pas | Evite une nouvelle brique d'infra sur un VPS partage ; un worker qui sonde Neon toutes les 5 s l'empeche de se mettre en veille (cout) | Allonger le sondage ; passer a LISTEN/NOTIFY ; deporter le rendu sur un serveur dedie |
| 2026-10-23 | Transcription | Whisper local gratuit (faster-whisper, modele small, int8, francais), fenetres de ~60 s autour des pics, audio HLS lu directement par ffmpeg | Pas de cout par minute ; pas de telechargement de VOD entiere ; qualite verifiee sur du francais parle | Modele `base` (plus rapide, moins fiable) ; API payante a la minute si le VPS est trop lent ; `WHISPER_MODEL` pour changer sans code |
| 2026-10-24 | Cadrage du streamer | Cadrage manuel (centre X/Y + zoom dans le back-office) ; reconnaissance par photos non faite | Un streamer solo avec une camera fixe n'a pas besoin de reconnaissance : une position reglee une fois suffit, c'est plus fiable et ne coute aucun CPU. La reconnaissance ne sert que pour les clips de react a plusieurs personnes (3 a 5 photos suffiraient) | Ajouter un script OpenCV (detection + reconnaissance par photos) qui calcule le centre par clip |
| 2026-10-24 | Illustrations | Dossier du streamer (tags + source), pas de recherche automatique | L'IA choisit mal une video a partir d'un recit ; le streamer sait ce qu'il a | Ajouter une recherche sur une banque libre (Pexels, Giphy) avec validation humaine |
| 2026-10-24 | Notation des moments | Note locale par defaut, API Claude si ANTHROPIC_API_KEY | Aucun cout ni secret obligatoire pour demarrer ; repli automatique si l'API echoue | Fournir la cle et choisir le modele via CLIPPEAK_LLM_MODEL |
| 2026-10-24 | Validation | Approuver ne publie ni ne paie : statut seulement ; modification du titre = nouveau rendu | Le titre est grave dans la video ; la publication reste une action du streamer | Ajouter une publication explicite (YouTube) avec confirmation a chaque clip |
| 2026-10-24 | Demarrage du worker | Manuel (pm2) tant que la migration n'est pas appliquee ; preflight bloquant | Evite de marquer des VODs en echec et de faire sonder Neon inutilement | Ajouter l'etape au workflow GitHub Actions une fois la migration appliquee |
